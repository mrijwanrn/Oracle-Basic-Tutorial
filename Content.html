Introduction to SQL

SQL stands for Structured Query Language. It is the standard language used for storing, manipulating, and retrieving data in a database.

SQL became a standard of the American National Standards Institute (ANSI) in 1986 and the International Organization for Standardization (ISO) in 1987.

SQL is a standard language for accessing and manipulating databases.

What is SQL?

  • SQL stands for Structured Query Language
  • SQL lets you access and manipulate databases
  • SQL became a standard of ANSI in 1986
  • SQL became a standard of ISO in 1987

What Can SQL Do?

  • Execute queries against a database
  • Retrieve data from a database
  • Insert records into a database
  • Update records in a database
  • Delete records from a database
  • Create new tables in a database
  • Create views in a database

Some of the Most Important SQL Commands

  • SELECT – Extracts data from a database
  • INSERT INTO – Inserts new data into a database
  • UPDATE – Updates data in a database
  • DELETE – Deletes data from a database
  • CREATE DATABASE – Creates a new database
  • ALTER DATABASE – Modifies a database
  • CREATE TABLE – Creates a new table
  • ALTER TABLE – Modifies a table
  • DROP TABLE – Deletes a table
  • CREATE INDEX – Creates an index
  • DROP INDEX – Deletes an index

SQL SELECT Statement

The SELECT statement is used to select data from a database.

Syntax: 
SELECT column1, column2 FROM table_name;
Example: 
SELECT ENAME, JOB FROM EMP;

SELECT DISTINCT

The SELECT DISTINCT statement is used to return only distinct values.

Syntax: 
SELECT DISTINCT column1 FROM table_name;
Example: 
SELECT DISTINCT SAL FROM EMP;

SQL WHERE Clause

The WHERE clause is used to filter records based on a specified condition.

Syntax: 
SELECT * FROM table_name WHERE condition;
Example: 
SELECT * FROM EMP WHERE DEPTNO = 10;

Operators used in WHERE clause:
<, >, <=, >=, <>, LIKE, BETWEEN, IN

SQL ORDER BY

The ORDER BY keyword is used to sort the result-set in ascending or descending order.

SQL AND / OR Operators

The AND and OR operators are used to filter records based on more than one condition.

AND Syntax: 
SELECT * FROM table_name
WHERE condition1 AND condition2;
Example: 
SELECT * FROM EMP
WHERE DEPTNO = 10 AND ENAME LIKE 'K%';
OR Syntax: 
SELECT * FROM table_name
WHERE condition1 OR condition2;
Example: 
SELECT * FROM EMP
WHERE DEPTNO = 10 OR DEPTNO = 20;

AND operator returns records if all conditions are TRUE.
OR operator returns records if any condition is TRUE.

SQL NOT Operator

The NOT operator is used to exclude records that meet a condition.

Syntax: 
SELECT * FROM table_name WHERE NOT condition;
Example: 
SELECT * FROM EMP WHERE NOT DEPTNO = 10;

SQL Sub Languages

SQL is divided into five sub languages, each used for a specific purpose in database management.

SQL is Divided into 5 Sub Languages

  1. DDL – Data Definition Language
  2. DML – Data Manipulation Language
  3. TCL – Transaction Control Language
  4. DRL – Data Retrieval Language
  5. DCL – Data Control Language

1. DDL – Data Definition Language

DDL commands are used to create, modify, and delete database objects such as tables, views, and indexes.

DDL Commands: CREATE, ALTER, DROP, TRUNCATE, RENAME, FLASHBACK, PURGE

CREATE Statement

The CREATE statement is used to create new database objects.

CREATE TABLE Syntax: 
CREATE TABLE table_name (
  column1 datatype,
  column2 datatype,
  column3 datatype
);
Example: 
CREATE TABLE EMP (
  EMPNO    NUMBER(4),
  ENAME    VARCHAR2(30),
  JOB      VARCHAR2(30),
  MGR      NUMBER(4),
  HIREDATE DATE,
  SAL      NUMBER(4),
  COMM     NUMBER(4),
  DEPTNO   NUMBER(3)
);

ALTER Statement

The ALTER statement is used to modify the structure of an existing table.

Syntax: 
ALTER TABLE table_name ADD column_name datatype;
Example: 
ALTER TABLE EMP ADD EMAIL VARCHAR2(50);

DROP Statement

The DROP statement is used to permanently delete a table.

Syntax: 
DROP TABLE table_name;
Example: 
DROP TABLE EMP;

TRUNCATE Statement

The TRUNCATE statement removes all records from a table, but the table structure remains.

Syntax: 
TRUNCATE TABLE table_name;
Example: 
TRUNCATE TABLE EMP;

RENAME Statement

The RENAME statement is used to change the name of a table.

Syntax: 
RENAME old_table_name TO new_table_name;
Example: 
RENAME EMP TO EMPLOYEE;

FLASHBACK Statement

The FLASHBACK statement is used to restore a dropped table.

Syntax: 
FLASHBACK TABLE table_name TO BEFORE DROP;
Example: 
FLASHBACK TABLE EMP TO BEFORE DROP;

PURGE Statement

The PURGE statement permanently deletes a table from the recycle bin.

Syntax: 
PURGE TABLE table_name;
Example: 
PURGE TABLE EMP;

2. DML – Data Manipulation Language

DML commands are used to manage data stored in tables.

DML Commands: INSERT, UPDATE, DELETE, MERGE

INSERT INTO Statement

The INSERT INTO statement is used to add new records into a table.

Method 1: Insert values for all columns 
INSERT INTO table_name VALUES (value1, value2, value3);
Example: 
INSERT INTO EMP
VALUES (7879, 'DEV', 'ACTING', 7788, DATE '2025-12-14', 5632, NULL, 20);
Method 2: Insert values by specifying column names 
INSERT INTO table_name (column1, column2)
VALUES (value1, value2);
Example: 
INSERT INTO EMP (ENAME, SAL, DEPTNO)
VALUES ('DEV', 35000, 10);

UPDATE Statement

The UPDATE statement is used to modify existing records in a table.

Syntax: 
UPDATE table_name
SET column1 = value1
WHERE condition;
Example: 
UPDATE EMP SET SAL = 2000 WHERE ENAME = 'SMITH';

Important: Always use a WHERE clause to avoid updating all rows.

DELETE Statement

The DELETE statement is used to delete records from a table.

Syntax: 
DELETE FROM table_name WHERE condition;
Example: 
DELETE FROM EMP WHERE ENAME = 'SMITH';

Important: Without WHERE clause, all rows will be deleted.

3. TCL – Transaction Control Language

TCL commands are used to manage transactions in a database.

TCL Commands: COMMIT, ROLLBACK, SAVEPOINT

COMMIT Statement

Saves all changes permanently in the database. 

COMMIT;

ROLLBACK Statement

Undoes changes that are not yet committed. 

ROLLBACK;

SAVEPOINT Statement

Sets a save point in a transaction to which we can rollback later. 

SAVEPOINT sp1;
ROLLBACK TO sp1;

Module 1: PL/SQL Basics

PL/SQL stands for Procedural Language / Structured Query Language. It is Oracle’s extension of SQL that allows us to write procedural code inside the database.

1. Introduction to PL/SQL

PL/SQL is a block-structured programming language that combines SQL statements with procedural features like conditions and loops.

It is mainly used to write business logic directly inside the database.

2. Advantages of PL/SQL

  • Improves performance by reducing network traffic
  • Supports variables, loops, and conditions
  • Better security for database logic
  • Easy integration with SQL
  • Reusable code using procedures and functions

3. PL/SQL Architecture

PL/SQL code is processed by the PL/SQL Engine.

If the code contains SQL statements, they are passed to the SQL Engine. Procedural statements are handled by the PL/SQL Engine itself.

4. PL/SQL Block Structure

A PL/SQL program is written in blocks. Each block has three sections:

  • DECLARE – Used to declare variables (optional)
  • BEGIN – Contains executable statements (mandatory)
  • EXCEPTION – Handles errors (optional)
Syntax: 
DECLARE
  -- variable declarations
BEGIN
  -- executable statements
EXCEPTION
  -- error handling
END;

5. Types of PL/SQL Blocks

There are three types of PL/SQL blocks:

  1. Anonymous Block – Written and executed once
  2. Procedure – Stored program that performs an action
  3. Function – Stored program that returns a value

Among these, Anonymous Blocks are mainly used for learning and testing.

In Simple Words

PL/SQL allows us to write logic inside the database using SQL + programming features.

Module 1: Oracle APEX Introduction

This module introduces Oracle Application Express (APEX), a low-code development platform used to build secure, scalable, and data-driven web applications.

1. What is Oracle APEX?

Oracle APEX is a low-code development tool provided by Oracle that allows developers to create web applications using SQL and PL/SQL.

APEX applications run inside the Oracle Database and do not require external application servers.

2. History & Versions of APEX

Oracle APEX was originally known as HTML DB.

It was later renamed to Oracle Application Express and is continuously improved with every release.

3. APEX Architecture

Oracle APEX works on a three-tier architecture:

  • Web Browser (Client)
  • Web Listener (ORDS)
  • Oracle Database

All business logic is stored inside the database using SQL and PL/SQL.

4. APEX vs Traditional Development

In traditional development, developers need separate layers for UI, logic, and database.

In Oracle APEX, everything is managed inside the database, which reduces development time and complexity.

5. APEX Use Cases & Advantages

Oracle APEX is commonly used for:

  • Enterprise internal applications
  • Rapid application development
  • Data-driven dashboards
  • Modern replacement for Forms
Advantages: Fast development, high security, low cost, and tight database integration.

Module 2: APEX Workspace & Environment

This module explains how to access Oracle APEX, create a workspace, and understand the APEX development environment.

6. Creating APEX Workspace

A Workspace is a logical area in Oracle APEX where applications, database objects, and users are managed.

One workspace can contain multiple applications and database schemas.

7. APEX Login & Navigation

After workspace creation, users can log in using the workspace name, username, and password.

Once logged in, the APEX home page is displayed.

8. APEX Home Dashboard

The APEX Home Dashboard provides access to:

  • App Builder
  • SQL Workshop
  • Team Development
  • Gallery
Most development work is done using App Builder and SQL Workshop.

9. Understanding APEX Components

Oracle APEX is divided into different components, each used for a specific purpose.

  • App Builder – Create and manage applications
  • SQL Workshop – Work with database objects
  • Team Development – Manage tasks and bugs

10. APEX Application Builder Overview

Application Builder is the core component used to design pages, regions, items, and logic.

It provides a low-code environment that reduces manual coding.

Using Application Builder, developers can create applications without writing large amounts of code.
